# SecondVoice visual system

## Subject and job

SecondVoice is a consent-first assistive speech instrument for people who can intentionally type or tap but cannot reliably speak. The first page has one job: let a judge understand and experience compose → stream → interrupt → revise in under 90 seconds.

## Palette

- Stage ink — `#121820`: the instrument body and 3D stage.
- Porcelain signal — `#e8edf0`: high-contrast text and heard-word surfaces.
- Assembly cobalt — `#3b63ff`: composition, connection, and system flow.
- Pulse coral — `#ff654d`: active speech and the primary action.
- Cut yellow — `#ffcf40`: interruption and the exact heard boundary.
- Mint resolve — `#8df7c4`: completed turns.

## Type

- Unbounded: restrained display type for the product thesis.
- Instrument Sans: body copy and controls.
- JetBrains Mono: live transport, latency, language, and event evidence.

## Layout

```text
│ mark            current state               replay/live  │

├──────────────────────────────────────────────────────────┤

```

## Signature

The sentence sculpture is an orbit of physical word segments around a central vocal form. As words become audible, segments become solid and emissive. Cancel visibly fractures the progression and leaves the unheard remainder translucent. This is the single expressive visual risk; controls around it remain quiet.

## Anti-template review

The first draft leaned toward the common warm-paper/serif/terracotta accessibility aesthetic. It was replaced with the visual language of a precision broadcast instrument: dark enamel, porcelain markings, cobalt signal routing, a coral speaking state, and an engineered horizontal timeline. The 3D form communicates speaking state and heard progress rather than serving as a generic AI orb.
