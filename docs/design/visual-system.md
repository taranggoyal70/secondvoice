# SecondVoice — Continuity direction

Confirmed user reference: https://github.com/aiden-guan/continuity and https://continuity-demo-tau.vercel.app/.

The previous dark cockpit and spectral terrain have been removed from the active page. The current composition uses warm paper, near-black text, thin rules, one rust accent, and a restrained dot-text treatment. The interface has two surfaces: intended message and playback evidence. Four manually selectable moments explain composition, speech, interruption, and revision. Technical protocol events are disclosed on demand.

Typography: self-hosted Instrument Sans and JetBrains Mono, with mono limited to annotations. Main content is framed at 1240px and collapses to one readable column on small screens.

Walkthrough data must remain explicitly marked as illustrative. Never invent latency, hearing accuracy, consent, agent activity, or benchmarks for presentation.

Visual comparison was performed in Chrome on desktop and at 390px width. Winning readiness depends on live audio evidence, interaction reliability, and submission artifacts in addition to design.
